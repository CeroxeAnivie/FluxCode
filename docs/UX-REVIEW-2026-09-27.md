# FluxCode 0.1.1 交互整改记录

本轮按用户完成工作的路径检查界面，而不是按控件数量判定体验。全程单线程推进，未使用 Computer Use。此记录区分已修正问题和复核后沿用的交互，不宣称所有人对所有操作都会满意。

## 已完成整改

- [x] 渠道导入：地址、密钥和模型列表为主流程；模型列表不再藏在“可选”折叠区域。直接导入默认保留全部模型，手工录入仍作为不提供目录的服务的兼容入口。
- [x] 模型管理：显示别名、原始 ID、搜索、单个移除、批量移除、单个恢复、全部恢复。删除后的目录刷新不擅自重新加入；别名同步到主窗口和独立工作区的模型选择器。
- [x] 模型刷新：默认合并新模型并保留本次未返回项；显式取消保留时才移除。当前使用模型有保护提示，不再要求先切换到其他渠道。
- [x] 表单防误操作：别名回车不提交整个渠道；有修改时取消可返回继续编辑；保存失败保留输入。渠道窗口关闭再打开保留内存草稿，不把密钥写入浏览器存储。
- [x] 设置：增加模型、外观、数据备份和诊断定位入口。未修改且已连接时保存仅关闭；断开连接时保留重连行为。分区定位不卸载编辑内容。
- [x] 扩展：MCP 编辑自动展开并聚焦名称，授权链接可直接打开；MCP 与插件页签切换保留草稿。插件添加成功清空来源、失败保留来源，加载失败可重试，成功操作有反馈。
- [x] 定时任务：关闭未完成草稿前提示继续编辑或放弃；保存期间不能关闭；成功后清空名称和指令但保留用户选择的间隔。
- [x] 终端：空状态区分未选择项目和已关闭会话，直接提供创建入口；关闭当前会话切换到相邻页签；新建编号不因删除旧会话重复；达到会话上限时不显示不存在的活动页签。
- [x] 搜索与整理：任务和项目重命名选中文本，搜索入口直接聚焦；命令面板在全部未归档任务中搜索后再限制结果数，能找到最近 100 条以外的任务。
- [x] 工作区文件搜索：切换项目清理旧结果，忽略旧请求回包；展开搜索即聚焦输入。失败保留输入并提供可恢复反馈。
- [x] 焦点：修复设置到渠道管理再关闭时的返回位置；不覆盖用户随后主动选择的输入框。
- [x] 视觉与反馈：模型行采用别名与原始 ID 的分层布局，长列表虚拟化，批量工具和底部操作可换行；明暗主题及 18px / 960px 布局复核。诊断报告导出提供成功反馈。
- [x] 结构：模型列表拆为独立组件，身份与显示名分离，Rust/TOML 校验和旧配置默认值保持兼容。

## 复核后保留的流程

| 用户工作路径                 | 复核内容与结果                                                                          |
| ---------------------------- | --------------------------------------------------------------------------------------- |
| 新任务、连续对话、运行中补充 | 发送失败保留草稿，IME 回车不会误发，排队与立即补充有区分，停止和失败状态有反馈          |
| 附件                         | 添加/去重反馈、图片预览、移除、Unicode 路径由现有实现处理                               |
| 历史、项目和独立窗口         | 搜索、批量组织、归档、恢复、独立草稿和模型选择沿用；本轮补搜索/重命名焦点和模型别名同步 |
| 文件与 Git                   | 现有草稿恢复、磁盘冲突提示、暂存/取消暂存、三方冲突编辑和恢复点操作保留                 |
| 内置浏览器                   | 右侧展开、拖动宽度、记忆宽度、弹窗期间隐藏、关闭恢复焦点、外部打开保留                  |
| 备份、恢复、导入导出         | 覆盖恢复有确认及保护备份；导出取消不丢编辑；导入失败保留有效预览；恢复确认门禁保留      |
| 中文/英文、主题/字号         | 默认中文、主题随系统、手动覆盖及字号记忆保留；本轮新文案均加入英语词典                  |
| 软件更新                     | 保持离线占位，不加入联网更新逻辑                                                        |

## 验证记录

- TypeScript 类型检查通过；118 项前端单元测试通过，包括翻译完整性。
- 10 项渠道 Rust 测试通过，包含 TOML 别名/排除项往返、非法字段、旧配置和大模型目录。
- Rust Clippy 所有目标通过，警告作为错误处理。
- 整套浏览器回归首轮 122 通过、7 失败；定位后修复两项实际行为问题，更新旧交互断言及原生主题测试替身。受影响流程和新增扩展/历史搜索测试共 12 项复跑全部通过。合计覆盖 131 个不同浏览器用例，未把一次失败写成一次全绿运行。
- 明暗主题截图检查；本轮无新增依赖，沿用 React、Radix、cmdk、TanStack Virtual 和现有 Markdown/终端/编辑器库。
- 安装包构建及资源核验结果在发布校验文件中记录。

## 配置兼容与原范围

`providers.toml` 增加可选 `model_labels` 和 `excluded_models`；空字段不写入，旧配置正常载入。0.1.0 严格拒绝未知字段，使用新字段后降级应恢复之前的配置备份，不能直接让旧版读取新字段。模型显示名只影响显示，不作为 Responses 模型 ID。

原定暂缓的签名、干净 Windows 安装/升级、缺运行组件、多账户/DPI、长期稳定性、完整网络/磁盘故障矩阵未改为“已通过”；上游维护通告也没有因本轮 UI 修改消失。全量产品验收不等同于这轮交互回归。
