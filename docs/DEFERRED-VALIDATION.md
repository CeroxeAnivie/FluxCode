# 暂缓的环境验收

按用户要求，这些验证不阻塞功能开发，也不撤销已完成实现。未执行的验证不宣称通过；交付时汇总说明。

- 多显示器、100%/125%/150%/200% DPI 和显示器热插拔。
- 不同 Windows 账户、干净虚拟机、无开发工具、缺 WebView2 的安装环境。
- 干净系统的首次安装、升级、卸载、重装及真实旧账户迁移。
- 需要新授权凭据的多家真实 Responses 服务兼容矩阵。
- 正式签名、时间戳和发布者身份：需要发布者证书配置。
- 真实系统睡眠/唤醒、物理磁盘断开、隔离磁盘满等特殊环境场景。
- Linux 和 macOS 不在当前交付范围。

## 已实现但保留环境限制

- 写入失败保护：草稿留存、失败提示、重试、另存和退出保护已接通。只读和权限不足已有本地原生记录，磁盘满/拔盘未执行。
- 安装器数据保护：仅明确选择删除数据且非升级时清除 data；真实安装矩阵未执行。
- 恢复后台连接和工作状态：检查连接、同步终端尺寸、读取活动轮次恢复漏失完成结果与队列状态。实际操作系统休眠未执行。

这些状态与真实缺失功能分开管理；多窗口协调现已实现，见 MULTIWINDOW.md。

## 扩展验收边界

- 长时连续运行的完整 CPU/句柄/私有工作集/日志增长 soak；当前已有有界缓存、日志轮换和浏览器基线。
- 真实 DNS/代理故障链路；本地401/429/503、错误SSE、断流及空闲超时已有证据。
- 完整第三方交互终端与屏幕阅读器组合；当前有真实PTY、隐藏/恢复、停止及窗口归属清理证据。
- 宿主强制退出恢复已通过，其他进程和每个文件写入边界的故障组合不冒充全面通过。
