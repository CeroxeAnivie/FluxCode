# 配置与渠道

FluxCode 的用户设置以 `FluxCode.exe` 所在目录的 `data/fluxcode.toml` 为准。可从设置窗口的“编辑 TOML”打开；密钥保存在系统凭据库或由环境变量提供，不写入 TOML。

## 数据跟随程序

- `data/engine-home/`：Codex 管理的 SQLite 数据库、JSONL 对话记录、引擎配置。
- `data/webview/`：WebView 本地存储，包括任务索引、草稿、队列和界面状态。
- `data/fluxcode.toml`、`data/providers.toml`：应用设置与全部渠道；`data/logs/` 保存轮换诊断日志。
- `data/storage-layout.toml`：记录数据目录版本和位置，用于迁移引擎数据库内的会话文件引用。

第一次升级到此布局时，发行版复制旧 Windows 用户数据目录，完整复制成功后才启用新目录，保留旧数据，不覆盖已有 `data`。复制失败不启用半份历史，不回退到另一处写入。迁移时须退出旧版；备份或搬动程序文件夹前也应退出应用，以保证 SQLite 和 WebView 文件一致。程序目录必须可写。

开发版默认同样使用可执行文件旁的 `data`，不自动导入安装版数据。`pnpm desktop:run` 无需安装；自动化测试可通过仅开发版识别的 `FLUXCODE_TEST_DATA_DIR` 使用隔离目录。`WEBVIEW2_USER_DATA_FOLDER` 若设置，必须与选定数据目录下的 `webview` 一致。

整个 `data` 可作为会话备份单元。项目文件、用户主动导出的文件和所引用的原始附件仍在用户选择的位置；系统凭据库中的密钥不会随文件夹拷走，需要在另一台电脑重新提供。

## 添加渠道

1. 打开侧边栏“渠道管理”，点击“添加渠道”。
2. 粘贴完整服务地址，例如 `https://example.com/v1`，以及访问密钥。名称可留空，默认使用服务地址。
3. 点击“导入并使用”（或按 Enter），自动获取并保存全部模型，然后连接。模型在会话输入框旁选择，可直接搜索。
4. 再次添加即可保留多个渠道，在渠道卡片上点击“启用”切换；“仅保存”可先收录备用渠道。服务没有 `/models` 接口时，在可选设置中手动填写模型 ID，多个模型用逗号或空白分隔，保存时自动加入。

模型目录查询不会发送对话，也不要求事先填写模型。目录完整保存（每个渠道最多 10,000 个模型），界面采用虚拟列表，搜索不会删减已保存的目录。命名渠道在 `providers.toml` 中，不包含密钥；同一服务地址的不同渠道使用独立凭据标识。导入失败保留输入以便重试，临时关闭渠道窗口也保留本次输入；未保存的密钥仅在当前窗口的内存中保留，不写入浏览器存储。

任务或终端运行时可以保存渠道，结束后再启用，不会为了切换渠道中断正在执行的工作。上下文与价格设置需要点击“保存设置”，未保存时离开会提示；外观调整立即生效。

模型目录成功只表示目录可访问，不证明所有模型都支持 Responses、所有推理档位或工具协议。

网络代理默认为空，使用宿主网络设置。只有在渠道的高级连接设置或 `[network].proxy_url` 中明确填写时，FluxCode 才覆盖引擎和新终端的代理环境；旧配置中已保存的代理值不会被自动改写。

## 设置的生效规则

| 内容 | 生效时机 |
| --- | --- |
| 语言、主题、字体、面板宽度 | 有效 TOML 编辑后自动更新界面 |
| 服务、代理、默认模型、上下文预算 | 外部编辑后等待任务、命令及交互终端空闲，再重连 |
| Shell、终端环境与命令限额 | 新启动的命令或终端使用新值 |
| 当前任务选择的模型与推理强度 | 仍由该任务记忆，不被全局默认值覆盖 |

运行中的终端不会被强制重启或注入新环境变量。需要更换连接时，先结束保留的交互终端会话；仅隐藏终端不会结束进程。重新载入窗口会复用相同配置的现有执行引擎。

文件监听采用 `notify`，支持编辑器通过临时文件重命名保存。250 毫秒合并写入事件；主文件最大 1 MiB。每次修改均先解析、校验，再替换运行中的配置快照。无效文件不覆盖有效状态，界面显示错误；修复文件后自动恢复。监听器失效时显示重启提示。

启动遇到无效文件时尝试备份，最后使用默认值，保留损坏文件供用户修复。设置保存使用临时文件、落盘和替换，并保留 `fluxcode.toml.bak`。界面内并发修改串行处理；连接表单使用版本检查，防止过期输入覆盖外部配置。已有值的行内注释及无关配置保留。

首次升级会将旧界面存储中的语言和主题迁移到 TOML，但不会覆盖用户已经明确配置的 `[appearance]`。会话、草稿、队列、滚动位置等运行状态仍使用各自的状态存储。

```toml
[appearance]
language = "zh-CN" # zh-CN / en / system
theme = "system"   # system / light / dark

[ui]
font_size = 14
sidebar_width = 246
inspector_width = 294
```

完整字段见 `config/fluxcode.example.toml`。定时任务为 `schedules.toml`；MCP 使用引擎目录的 `config.toml` 及显式 MCP 重载。主文件的自动重载不能泛化为所有辅助文件都已具备实时界面同步。AGENTS.md 仍归用户管理，ENVIRONMENT.md 仍为生成的环境说明。

## 网页链接

Markdown 由 `react-markdown` 与 `remark-gfm` 渲染。用户和助手消息中的 HTTP(S) 链接突出显示，点击后通过 Tauri opener 交给系统默认浏览器；不会创建应用内浏览器。拒绝脚本、数据、本地文件协议和带登录凭据的 URL。本地文件引用不被当作网页链接打开。
