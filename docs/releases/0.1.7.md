# FluxCode 0.1.7 — 子智能体、统一材质与顺畅过渡

日期：2026-10-04。Windows x86_64，复用现有 Codex 0.157.0 引擎二进制。

- 当前任务下方展示子智能体，点击后在右侧查看状态、消息、Markdown 思考摘要及工具活动。支持发现后代智能体、实时事件、失败重试和父任务切换隔离。查看记录不会恢复或启动智能体。
- 启用原生双向团队协作：主智能体可创建、列出、发送消息、中断、追加任务并恢复子智能体；子智能体可向父级和同级发送消息。去掉原来的小额产品配额，使用上游可表示的上限；实际运行仍受内存、服务配额和费用约束。
- 默认运行身份、系统提示、环境说明和工具指导使用 FluxCode。所有已选渠道模型应用同样的团队能力配置；自定义模型不再因为未知型号而缺少子智能体工具。上游文件名和法律声明保留。
- 消息记录实际模型 ID，不显示渠道或产品名称；新记录按轮次保存，切换模型不改写旧记录。没有来源记录的历史显示“模型未记录”。运行提示保留“正在处理”、计时和动态圆点；减少动态效果模式使用柔和明暗变化。
- 原生亚克力统一到标题栏、侧栏、聊天主区和右侧面板，背景色遮罩提高到 90%，输入框保持实底。系统不支持材质、关闭透明或开启高对比度时仍采用实色。
- 侧栏、文件、子智能体、浏览器和终端面板提供短促开关过渡；项目列表行使用位移动画，普通折叠区在支持的 WebView2 中使用原生高度过渡。拖动宽度即时跟手，动画不改变终端生命周期或文件编辑状态。系统减少动态效果设置会禁用伸缩动画。
- 稳定 Markdown 渲染组件，减少布局变化时重建链接和图片节点，保留浏览器关闭后的键盘焦点。

没有新增第三方依赖，没有数据库结构迁移。模型来源使用现有持久化界面状态机制；旧版本可以忽略新增记录。子智能体面板最多展示最近 2,000 条内容并明确提示截断，底层完整历史不被删除。

验证使用本地 Responses 服务和已有引擎，无生产调用。原生团队工具已实际执行；CSS 材质和动效经过浏览器回归，最终桌面材质观感仍需用户人工验收。安装包未签名；此前暂缓的干净系统、长期稳定性、系统组合及正式签名验收保持暂缓。
