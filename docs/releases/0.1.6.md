# FluxCode 0.1.6 — 可见浏览器操作、图片消息与文本编辑器

日期：2026-10-04。Windows x86_64，复用 Codex 0.157.0。

- 智能体自动发现内置浏览器工具，操作时展开主窗口右侧面板，显示当前操作。支持实际元素快照、点击、填写、下拉选择、勾选、按键、悬停、滚动、截图以及网页弹窗确认或取消，包含 iframe 内的元素。
- 点击“停止并接管”可中止正在等待的操作，并暂停后续智能体操作；点击“允许智能体继续”后恢复。导航后的旧元素引用会被拒绝，页面提交不会因为观察失败而自动重放。接管前已生效的操作不会撤销。
- 图片可以选择、粘贴或拖入输入区，显示缩略图，点击后支持缩放和关闭。支持纯图片发送、图片历史、Markdown 图片与浏览器工具截图；实际消息使用图片输入。图片是否能被理解取决于所选模型和渠道的视觉能力。
- 图片副本持久化到 `data/attachments`，不会依赖剪贴板或临时原图；相同内容去重。支持 PNG/JPEG/WebP/GIF，限制单张 20 MiB、边长 8192、总像素 1600 万。预览使用最多 2048 边长的静态图，发送保留原始文件。GIF 预览为静态帧。
- 文件面板直接进入 CodeMirror 编辑器，可新建项目内文本文件、撤销、查找替换、自动换行、Ctrl + S 保存、引用到聊天。创建不覆盖已有文件，保存保留原有的外部修改检测和草稿恢复机制。
- 亚克力由 Windows DWM 原生合成。主窗口和项目窗口共用主题与材质策略；系统关闭透明、高对比度、节能或系统不支持时使用实色背景。

浏览器复用系统 WebView2，安装包内置受校验的 Node 24.21.0 与 Playwright 1.63.0，无需用户另外安装 Node 或浏览器。没有数据库格式迁移。备份包含持久化图片，排除浏览器缓存。

截图或模型工具调用中的网页内容仍属于不可信输入；浏览器页面不能调用本地应用命令。浏览器下载仍提示在系统浏览器中进行；本轮没有加入上传文件或任意脚本执行接口。多窗口共用主窗口中的智能体浏览器。

本轮使用本地 Responses 测试服务和实际 WebView2 验证，没有使用生产额度，也没有把真实渠道凭据写入项目。自动化页面操作验证不等同于对所有模型自主选工具能力的保证。安装包仍未签名；先前暂缓的干净系统、长期稳定性及系统设置组合验收维持原范围。
